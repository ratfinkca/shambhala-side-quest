# Asset provenance and runtime artwork

`themes/forest-freakout/*.webp`: original AI-generated title, woodland backdrop, Disco Boots, Pool Noodle, Moth Charm and Friendship Bracelet artwork created for this project on 2026-10-16 using the approved Forest Freakout concept. Optimized locally to WebP (title/backdrop at most 1200px; perk art 480px).

`themes/previews/*.webp`: reduced concept-board previews of Moonlit Mycelium and Neon Field Trip. These are retained concept-board previews; both themes now have complete implementations and their own asset folders below.

Fonts are bundled locally from the official google/fonts repository: Lilita One (`ofl/lilitaone/LilitaOne-Regular.ttf`) and DM Sans (`ofl/dmsans/DMSans[opsz,wght].ttf`). Their SIL Open Font License files are retained alongside each font in `fonts/`. No runtime font service is used.

## Moonlit Mycelium

`themes/moonlit-mycelium/*.webp`: original artwork generated with built-in imagegen for the approved Moonlit concept, 2026-10-16. Title/backdrop optimized to at most 1200px; individual perk art to 480px. UI uses a system Georgia serif stack with the existing local DM Sans body font; HUD numbers stay sans-serif for readability.

Prompt direction: luminous woodland storybook, midnight navy, silver sage foliage, lavender mushrooms, pale golden moonlight. Title: square poster, cloaked wanderer facing a glowing tent village, exact “SHAMBHALA SIDE QUEST” title in enchanted serif, no UI or additional text. Backdrop: 3:2 woodland frame with quiet dark center, crescent moon, mushrooms and fireflies at edges, no text. Perks: four separate square illustrations of celestial platform boots, curved foam pool noodle, luna moth/crescent charm, and woven friendship bracelet, no text/UI/borders.

## Neon Field Trip

`themes/neon-field-trip/*.webp`: original artwork generated with built-in imagegen for the approved Neon concept. Title/backdrop optimized to at most1200px; individual perks to480px. Uses the existing locally bundled Lilita One and DM Sans fonts.

Prompt direction: playful psychedelic screenprint/sticker art, deep purple forest, acid lime, hot pink, cobalt and orange, bold ink outlines. Title: square poster with happy moth, smiling mushrooms and festival dancers, exact “SHAMBHALA SIDE QUEST” lettering, no UI or extra text. Backdrop: landscape forest edge frame with quiet purple center, angular pines and neon mushrooms/moths/stars, no text. Perks: four separate square illustrations of rainbow platform boots, smiling pink hollow foam pool noodle, happy multicolor moth, and colorful beaded friendship bracelet; cream sticker outlines and no text or UI.


## Procedural artwork and sound

The four experience-unlocked perk cards (Crowd Surfer, Bass Battery, Encore, Sweet Tooth) use theme-coloured SVG generated by `src/perk-art.js`. Avatar wardrobe/totems/flourishes, gameplay pickups, mud/bass zones, near-miss rings and concert lighting are drawn in code. They do not require external sprite downloads.

Stage arrangements and sound effects are synthesized locally through Web Audio (`src/music.js`, `src/audio.js`). There are no streamed festival recordings, external commercial tracks or runtime music-service dependencies in this build. Music direction and stage arrangements are separate from the selectable menu themes.

The M3 Endless souvenirs (Spore Sprout, Mixtape Totem, Mycelium Threads and Aurora Ribbons) are original procedural artwork in `src/Avatar.js` and `src/endless-cosmetics.js`. Their fixed drawing commands create no external assets or persistent particle systems; reduced-motion versions freeze animation and drop response.

M4 Wavy Colours uses bounded procedural liquid-light strokes in `src/candy-colours.js`, behind field objects. It uses no external imagery, shaders or music assets.

Bass interface preview: cone-origin wavefronts and player pressure/protection marks are bounded procedural graphics in `src/bass-feedback.js`. The on-field meter uses CSS, text and a Unicode icon; no external artwork was added.

## Edition ownership (M0)

The three `themes/*/title.webp` posters contain embedded Shambhala lettering and belong only to the SMF edition. Generic uses a neutral text title over a shared backdrop; final generic title art is deferred. The unused `themes/previews/*.webp` concept boards are excluded from both runtime artifacts. Backdrops and the four perk illustrations per theme are shared neutral artwork, as are local fonts and their licenses. `playtest-data.html` is shared development notice copy; its GitHub contact remains the project contact. `ASSETS.md` is source provenance, not a runtime download.

`build/edition-assets.js` explicitly allowlists runtime public files for DEV and production; adding an asset requires assigning it to an edition there. CSS-imported neutral fonts are also emitted by Vite.
