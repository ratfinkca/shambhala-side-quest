## Architecture

Vite/Phaser static frontend; the generic edition is publicly hosted on GitHub Pages. `src/main.js` selects `src/game-entry.js` for generic or `src/smf-tour/entry.js` for SMF, with the other gameplay entry pruned from its build. `src/editions/` owns trusted identity, route/catalogue and venue content; `src/smf-tour/` owns the pure tour model, bounded atomic store, scene, menus and permanent souvenir display. Pure game/run/stage rules live in `src/game.js`, `src/run.js`, `src/stages.js`, `src/endless.js`; Phaser rendering in GameScene/StageRenderer/Crowd/Avatar. `src/screens.js` controls navigation and `src/results-view.js` renders score decisions. `src/progression.js`, profile/storage own local XP and saves. Theme registry/art and stage music/lighting are independent.

`src/online/` talks to the Supabase arcade functions. `src/playtest/` owns consent, aggregate measurement and bounded best-effort transport. Supabase functions validate exact payload allowlists; private-schema RPCs own writes/reads. Analytics and arcade identities/storage are separate.
