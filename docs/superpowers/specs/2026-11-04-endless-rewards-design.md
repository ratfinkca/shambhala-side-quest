# M3 — Endless souvenirs

Approved concept: four device-local achievements and cosmetic rewards. No score rule, perk strength, consent, network payload or backend changes.

| Achievement | Earn condition | Reward |
|---|---|---|
| The Night’s Just Starting | Clear 4 stages in one Endless run | Spore Sprout hat; luminous mushroom cluster and drifting spores |
| Remix Artist | Swap an equipped perk, then clear the immediately following stage | Mixtape Totem; turning reels and a loose ribbon that moves during drops |
| Trail Mixer | Clear all six authored layout variants, across runs | Mycelium Threads onesie; midnight fabric with travelling fungal colours |
| Still Dancing | Clear 12 stages in one Endless run | Aurora Ribbons flourish; short translucent ribbons, brighter during drops |

Thresholds are preview targets, not a balance conclusion. Award at a qualifying stage end, independently of score saving/posting. Failure, partial stages, keeping a build, adding a perk and cancelled swaps do not grant new achievement credit. New challenges start at zero for all existing profiles; retain all earlier unlocks. Persist bounded distinct layout IDs and personal best clears, plus one Remix completion flag. Existing stage receipts prevent duplicate stage XP/reveals. No run recovery or cloud sync.

Show best clears, individual layout collection and the swap condition in wardrobe. Every new piece has a locked animated preview, and earned pieces remain previewable. Cosmetic artwork stays close to the avatar and has no gameplay effects. Reduced motion draws stable versions of every effect. A development-only reward lab uses an isolated in-memory profile, no scores/XP/analytics writes, and is removed from production.
